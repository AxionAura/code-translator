# Benchmark corpus attribution

All files under `benchmarks/corpus/` and `benchmarks/projects/` were authored for
this repository as benchmark inputs. They are licensed under the repository's MIT
license (see `LICENSE`). No third-party source code is vendored here; if external
material is added later it must include its license and source URL in this file
and must pass the repository's license rules (AGENTS.md §5).

The micro and perf suites generate their inputs in memory and contain no external
material.
